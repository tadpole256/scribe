# Security policy

## Supported versions

Security fixes are applied to the latest released version of Scribe.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private security advisory feature for this repository, or contact the maintainer through the email address listed on the GitHub profile. Include a clear reproduction path, impact, and suggested mitigation if available.

Scribe must not collect, upload, or expose source code, issue data, or agent workspace files without explicit user approval.
